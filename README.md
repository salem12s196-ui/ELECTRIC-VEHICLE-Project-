# Electric Vehicle (EV) High-Efficiency Prediction

## Project Overview

This project applies an end-to-end machine learning workflow in Python to classify Electric Vehicles (EVs) into **High-Efficiency (`1`, efficiency score > 5.0)** versus **Standard-Efficiency (`0`)**. The Streamlit web application loads the best-performing model pipeline and displays both the predicted efficiency tier and its probability score.

## Machine Learning Models

The project compares two supervised classification models:

- **Decision Tree Classifier** (`DecisionTreeClassifier`)
- **Bernoulli Naive Bayes** (`BernoulliNB`)

Both models are tuned using `RandomizedSearchCV` with 3-fold Stratified Cross-Validation optimizing the **F1 score**. The winning model pipeline is exported to `ev_efficiency_model.pkl` for deployment in Streamlit.

## Dataset & Licensing

The project uses a single 250,000-record dataset of Electric Vehicle specifications, pricing, and performance metrics:

- `EVDataset.csv` (originally `EV_dataset.csv`) — 250,000 records and 22 columns used for data cleaning, EDA, and feature engineering. The script splits this dataset 80/20 using `train_test_split` into 200,000 training rows and 50,000 validation rows.

**Target Variable (`target_high_efficiency`):**
- `0` = Standard-Efficiency EV (Efficiency score <= 5.0)
- `1` = High-Efficiency EV (Efficiency score > 5.0)

**Dataset Source:**
- **Source:** Srijan Upadhyay, *EV_Dataset: High-Dimensional EV Dataset for Advanced Machine Learning and Data Exploration*, Kaggle: https://www.kaggle.com/datasets/srijan1upadhyay/ev-dataset
